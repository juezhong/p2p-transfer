# p2p-transfer v0.1.2 — 本机文件摘要与 GET 提示优化

本次从 `v0.1.1` 正式版继续开发，不修改网络协议或 SDK。

## 更新内容

- 交互命令 `sha256 <本机文件>` 和 `md5 <本机文件>`。支持相对于本机 `lcd/lpwd` 的路径、绝对路径、含空格路径的双引号输入及 Tab 本地文件补全。
- 计算仅读取本机已授权文件句柄；固定 128 KiB 缓冲，独立阻塞任务处理文件 I/O，避免影响 QUIC 事件循环，操作结果包含摘要十六进制字符串和绝对文件路径。
- 发送端为对方的 GET 请求回传文件时不再打印 `[GET] 已回传 N 字节`；发送端保留传输进度。接收端仍显示 `[文件] 已接收并验证 N 字节（SHA-256 OK）` 及 GET 批次完成提示。

## 安全及兼容性

- MD5 不具备安全抗碰撞性，仅用于非对抗性的快速文件比较；完整性与安全验证请使用 SHA-256。
- 对现有 Control/Data 协议无变更；v0.1.1 的双端任务状态协议仍适用。
- Linux x86_64 ↔ RK3568 实机 2GiB 校验、跨 NAT/CGNAT、断线重传仍需现场验收。
